### Seis etapas continuas de procesamiento

## Diapositiva 7: Diagrama Completo del Flujo Automatizado
# Flujo Lógico y Árbol de Decisiones
### Ruta de éxito, bifurcaciones de control y manejo de excepciones
- **Entrada:** Webhook autenticado con identificador único de ejecución.
- **Control de Idempotencia:** Si ya fue procesado -> Abortar duplicado. Si es nuevo -> Continuar.
- **Validación Estructural:** Si el archivo está corrupto -> Disparar Workflow 3 de error. Si es válido -> Procesar.
- **Regla Determinista Inquebrantable:**
  - TMO <= 20s: APROBADO (Verde)
  - TMO > 20s: REQUIERE REVISIÓN (Rojo) / EN OBSERVACIÓN (Amarillo)
- **Revisión por IA:** Inferencia contextual que explica la causa del resultado sin alterar la regla matemática.

## Diapositiva 12: Replicación del Proyecto
# Cómo Replicar esta Solución desde Cero
### Guía rápida de implementación independiente
1. **Requisitos:** Node.js 18+, Python 3.9+ (openpyxl), Supabase / PostgreSQL, Gmail SMTP.
2. **Esquema de Base de Datos:** Ejecutar `database/schema.sql`, `rls_policies.sql` y `functions.sql`.
3. **Variables de Entorno:** Configurar credenciales en `backend/.env`.
4. **Ejecución:** Iniciar Backend (`npm run dev` en `backend/`) y Frontend (`npm run dev` en `frontend/`).
5. **Workflows n8n:** Importar `n8n/workflows/master_call_center_tmo_workflow.json`.
- **Manual Completo:** Consultar `docs/REPLICATION_MANUAL.md`.
