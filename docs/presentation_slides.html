Diapositiva 2 • Problemática

La Realidad Operativa del Call Center Tradicional

3 a 5 Horas Diarias Perdidas

Supervisores consolidando manualmente hojas de cálculo dispersas descargadas de múltiples PBX.

Falacia Matemática del TMO

Cálculo erróneo de promedios simples de agentes, ignorando la ponderación por volumen real de llamadas.

Pérdida de Trazabilidad

Revisión subjetiva y tardía que impedía detectar a tiempo silencios excesivos o abandonos críticos.

Descarga Manual ➔ Manipulación Celda por Celda ➔ Error de Fórmula ➔ Envío Tardío sin Auditoría

Diapositiva 4 • Solución Implementada

Ecosistema Tecnológico Integrado

1. Frontend Web (React 19)

10 secciones interactivas: KPIs en tiempo real, gráficos con línea de umbral objetivo y 2 gráficos de dona independientes.

2. Backend API & Idempotencia

Node.js con Express y TypeScript, protección criptográfica SHA-256 contra reintentos accidentales.

3. Reportes Excel de 4 Hojas

Motor Python openpyxl que inserta gráficos nativos de barras y dona dentro del libro generado.

4. Workflows n8n & Asistente IA

Automatización modular con looping por lotes de agentes, auditoría contextual y entrega por Gmail SMTP.

Diapositiva 12 • Replicación

Guía de Replicación Rápida

1. Requisitos: Node.js 18+, Python 3.9+ con openpyxl, PostgreSQL / Supabase, n8n.

2. Base de Datos: Ejecutar database/schema.sql, rls_policies.sql y functions.sql.

3. Entorno: Configurar backend/.env con credenciales de Supabase y SMTP.

4. Workflows: Importar n8n/workflows/master_call_center_tmo_workflow.json en n8n.

5. Iniciar: Ejecutar npm run dev en las carpetas backend/ y frontend/.

Consulte el documento independiente docs/REPLICATION_MANUAL.md para el paso a paso detallado.
